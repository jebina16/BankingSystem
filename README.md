🏦 Banking Management System
📖 About the Project

The Banking Management System is a simple console-based Java application that performs basic banking operations. It is developed using Core Java and ArrayList to demonstrate object-oriented programming concepts and menu-driven application development.

✨ Features
Create a Bank Account
Deposit Money
Withdraw Money
Check Account Balance
View All Accounts
Exit the Application
🛠 Technologies Used
Java
ArrayList
Scanner
Object-Oriented Programming (OOP)

Compile the Java files.

javac Main.java

Run the application.

java Main
